# ZeroOne V2.0.4 リリースノート

## 概要

ZeroOne V2.0.4 は、V2.0.3 のエラーチェックで確認された制御フローの問題を修正し、セルフホスティングを意識した標準ライブラリ機能を追加したバージョンです。

## 修正

- `FOR` 内の `CONTINUE` が更新式を飛ばして無限ループになる問題を修正。
- `TRY` をネストしたときに内側の例外処理が外側の例外ハンドラを破壊する問題を修正。
- `TRY/CATCH/FINALLY` の正常終了時に、外側のネストした TRY を維持できるよう例外ハンドラ管理を改善。
- `NEXT` のイテレータ終了は V2.0.3 の専用センチネル方式を維持。

## 新規追加: セルフホスティング向け20機能

1. `CHARAT` - 文字列から1文字取得
2. `STR_INDEXOF` - 文字列内の検索位置を取得
3. `ISDIGIT` - 数字文字判定
4. `ISLETTER` - 文字判定
5. `ISSPACE` - 空白文字判定
6. `ISALNUM` - 英数字判定
7. `ASCII` - 文字をコード値へ変換
8. `SOURCE_LINE` - ソースコードの指定行を取得
9. `ERROR_AT` - 行・列情報付きエラーを発生
10. `WARNING` - 警告を標準エラーへ出力
11. `READ_BYTES` - バイナリファイルをバイト配列として読む
12. `WRITE_BYTES` - バイト配列をバイナリファイルへ書く
13. `PACK_INT` - 整数を4バイトへ変換
14. `UNPACK_INT` - 4バイトから整数へ復元
15. `PATH_NORMALIZE` - パスを正規化
16. `BASENAME` - パスからファイル名を取得
17. `DIRNAME` - パスからディレクトリ部分を取得
18. `EXTENSION` - 拡張子を取得
19. `READ_LINES` - テキストを行配列として読む
20. `FILE_LINES` - テキストファイルの行数を取得

## テスト

V2.0.4 では既存テストと新規回帰テストを実行し、`29 passed` を確認しています。

特に以下をテストしています。

- FOR + CONTINUE
- 多重ネスト TRY/CATCH
- ネスト TRY の正常終了 + 外側例外処理
- 新規20標準ライブラリ機能
- バイナリ読み書きと整数のpack/unpack
- ERROR_AT
- Native ID の重複チェック
